A portfolio is usually a long page: a hero, a few cards, a contact form. It works, but it all looks the same, and it does not say much about _how_ someone thinks.

So I built mine as a tiny operating system.

## The idea

Each part of me is an app:

- **Explorer** for my projects, told as _context → problem → solution_
- **Terminal** for the "about me", because typing `whoami` is more fun than reading a paragraph
- **Trash** for the bugs I survived, because debugging is half of the job
- **Paint** and **Notes** for the creative side

## The rules I gave myself

1. **Content before animations.** No bouncing buttons until every window had something real inside.
2. **Mobile is not optional.** A fake desktop on a phone is a bad joke, so phones get a simple launcher with cards.
3. **The URL is the truth.** `/projects/kc-media` opens the right window, so every page can be shared.
4. **One small pull request per step.** Easy to review, easy to undo.

## What I learned

Building a "fake" OS forced me to think about real things: focus management, keyboard navigation, state that lives in one place, and what happens when two windows want the same screen.

Good UX should feel obvious. Getting there is not.
